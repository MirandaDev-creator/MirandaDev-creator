## 📂 Meus Projetos

### 📚 Banco de Dados — Biblioteca

Sistema desenvolvido em **Python**, simulando um banco de dados para uma biblioteca.

O projeto trabalha com informações relacionadas a livros e usuários, com o objetivo de praticar conceitos de programação e gerenciamento de dados.

**Tecnologias:**

* Python
* Banco de dados

---

### 🤖 Chatbot com API

Chatbot desenvolvido em **Python** utilizando uma **API** para obter respostas mais complexas.

O projeto foi criado com o objetivo de aprender como integrar APIs externas a uma aplicação e desenvolver um sistema de conversação.

**Tecnologias:**

* Python
* API
* Integração com serviços externos

---

### 🎥 Analisador de Vídeos do YouTube

Projeto desenvolvido para analisar vídeos do **YouTube** através de uma API.

A aplicação recebe o link de um vídeo e utiliza a API para obter informações que podem ser utilizadas para gerar uma análise ou resumo do conteúdo.

**Tecnologias:**

* Python
* API
* YouTube API
